## 指摘
### [R1-1][High][includes/class-jp4wc-security-checks.php `xmlrpc()`、SecuritySettings.js `allowedUnprotected`]
許可リストがあるときの A-04 が `login_protected_by_other_means()` で pass していた。これには xmlrpc.php を守らないもの（wp-login.php の `.htaccess` 制限、ログイン URL を移すだけの `wps-hide-login` / `rename-wp-login`）が入り、そのときログイン試行回数の制限も眠るので、許可メソッドでパスワードを無制限に試せるのに A-04 が pass、画面の警告も出なかった（自分とサブエージェントの両方が検出）。
**対応:** `JP4WC_Security_Checks::xmlrpc_login_protected()` を追加（JP4WC の制限が動作中・Jetpack の総当たり防御・ログイン URL 系を除く既知プラグイン）。A-04 と、security API のビュー `xmlrpc.login_protected`（画面の警告）が同じ判定を使う。

### [R1-2][Medium][includes/class-jp4wc-xmlrpc-guard.php `record_request()` / `store()`]
記録は常時動き、multicall で全メソッド（core 75 + system 3）を呼ぶと 1 リクエストで 200〜300 クエリの wp_options 書き込みになった。UA を毎回変えると info 行の 60 秒の間引きも効かない。
**対応:** 1 リクエストで記録するのは 10 メソッドまで。info 行は IN で 1 回読み、count は 1 文の複数行 `INSERT … ON DUPLICATE KEY UPDATE`。info 行は新規か前回から 60 秒以上のときだけ書く（UA の違いでは書かない）。成功したログインのクライアントは `login_user_agent` に別に持つ（失敗の試行では上書きされない）。

### [R1-3][Medium][tests]
`authenticate` / `wp_login_failed` → shutdown の記録という実際の経路と、A-04 の `.htaccess` / ログイン URL 系のケースのテストが無かった。
**対応:** `XMLRPC_REQUEST` の代わりにテストで差し替える private static を置き、`$server->call()` の誤パスワード・正しいパスワードが failed / login として記録されること、記録後にリセットされること、XML-RPC でなければ記録しないことを確認。A-04 に `.htaccess`・`wps-hide-login`・`rename-wp-login`（fail）、`loginizer` 併用・Jetpack（pass）を追加。

## Low（この回で直したもの）
- [R1-L1] 4 バイト文字を含む UA が utf8mb3 のテーブルで info 行の書き込みを失敗させ、count も書かれなかった → UA は印字可能な ASCII だけ残して 200 文字に切る（`clean_user_agent()`）。count を先に書き、info の失敗は count に影響しない。
- [R1-L2] 上限の数に期限切れの行も入っていた／他プラグインが `xmlrpc_enabled` を false にしたときのログイン試行が open に数えられていた → 上限に達したら期限切れを消して数え直す。`$server->error` が 405 なら refused。
- [R1-L3] XML-RPC の仕様で使える `:` と `/` が許可リストで捨てられた → 許可する。
- [R1-L4] 「アプリケーションパスワードには影響しない」は XML-RPC 経由のものに当たらない → 「REST API（REST API で使うアプリケーションパスワードを含む）」に。

## Low（backlog へ）
- [R1-L5] WooCommerce が Jetpack の接続を同梱するので、多くのサイトで `?for=jetpack` を付けた要求は Jetpack が引き受ける（コア・パスワードログインは外れ、Jetpack のメソッドだけになる）。このとき Jetpack の優先度 10 のフィルタより後に他のプラグインが足したメソッドは guard されずに残る（パスワードログインは無いので試行はできない）。docblock とテストの説明は実際の動きに合わせた。
- [R1-L6] count の `CAST(option_value AS UNSIGNED)` を SQLite（SQLite Database Integration）で確かめていない。
