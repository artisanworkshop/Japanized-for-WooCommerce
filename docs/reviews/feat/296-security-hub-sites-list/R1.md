## 指摘
### [R1-1][High][plugins/artws-security-hub/includes/class-artws-sec-admin-sites.php handle_download() / csv_batches()]
該当する登録が 0 件（登録が無い、または一致しない検索）だと CSV のダウンロードが fatal。`handle_download()` が `current()` で先読みした時点で、yield せずに return したジェネレーターは閉じており、`write_csv()` の `foreach` が素の `Exception: Cannot traverse an already closed generator` を投げる（`Artws_Sec_Feed_Exception` ではないので捕まらない）。ヘッダー・BOM・見出し行の後に致命的エラーの画面が付き、recovery mode のメールも飛ぶ。テストの `csv()` は先読みしない経路しか通っていない（自己レビューとサブエージェントの両方が `php -r` / 実クラスで再現）。
**修正方針:** `csv_batches()` は空でも 1 回 yield する。先読みを `open_csv()` に切り出し、テストも同じ経路（先読み → 書き出し）を通す。

### [R1-2][Medium][plugins/artws-security-hub/includes/class-artws-sec-site-stats.php suppress_bands()]
「隠したマスが 1 つなら次に小さいマスも隠す」だけでは、割り出せる場合が残る。例 A（50 サイト、売上 15/8/5/5/5/2、未送信 10）: 「—」の B2 は 5 以上で、かつ規則（最小のものを隠す）から残った表示中の最小値 5 以下 → 5 と決まり、B5 = 2 と分かる。例 B（B4 = B5 = 4）: 隠したマスは 2 つだが、合計 8 と各 4 以下から両方 4 と決まる（どちらも実クラスで再現）。受け入れ条件「差し引きで分かるときは…「—」」を満たしていない。
**修正方針:** 隠したマスごとに、表の合計と各マスの範囲（Under 5 は 0〜4、「—」は 5 以上で表示中の最小値以下、未送信は両表で同じ値）から取りうる範囲を求め、一つに決まるマスがある間は、その表の表示中の最小のマスを隠す。

### [R1-3][Medium][plugins/artws-security-hub/tests/Unit/test-site-stats.php]
「登録が消えた診断（孤立した診断）を集計に数えない」にテストが無い。`latest_requests_by_site_key()` の `INNER JOIN` を `LEFT JOIN` に変えても全件 green（サブエージェントの変異で確認）。
**修正方針:** 親のサイト行を消した診断を置き、`sites` に数えないことを確かめるテストを足す。

### [R1-4][Medium][plugins/artws-security-hub/includes/class-artws-sec-admin-sites.php csv_value() / README.md / test-admin-sites.php]
CSV インジェクションの説明とテストが、実際の入口と合っていない。`Artws_Sec_Scan_Request` は `site_url` を `https?://` 始まり、`locale` を英字始まりに限るので、この 2 つは `=` などで始まらない。送信側が自由に決められるのは `jp4wc_ver` / `wp_ver` / `wc_ver` / `php_ver`（制御文字以外の 1〜64 文字）で、その列のテストが無い（処理は全列にかけているので動作は正しい）。
**修正方針:** docblock・README を版の列に直し、テストに版の列の例（`=`・`+`・`-`・`@`）を足す。
