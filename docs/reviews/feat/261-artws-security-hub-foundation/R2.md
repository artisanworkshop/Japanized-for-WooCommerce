## 指摘
### [R2-1][Medium][tests/fixtures/security-feed/README.md(V3 からの変換)]
R1-2 で入れた「レコード単位で除外し、stale は取得・生成そのものの失敗時だけ」は安全側に倒れない。Wordfence V3 の形式が変わって大半が Schema に合わなくなると、ほぼ空のフィードが `stale: false` で配信され(`vulnerabilities: {}` も Schema を通る)、クライアントは「脆弱性なし」と表示する。#262 の受け入れ条件(不正データで前回の生成物を残し stale)とも食い違う。
**修正方針:** 除外の割合や件数の減少が閾値(S1 で決める)を超えたら生成失敗として前回のファイルを残し stale を立てる、と追記。→ 9b53b66 で修正
