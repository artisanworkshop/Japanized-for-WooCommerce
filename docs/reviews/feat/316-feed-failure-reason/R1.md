## 指摘
### [R1-1][Medium][src/js/jp4wc/admin/settings/components/SecuritySettings.js（FeedFailure）]
`has_data` が true で `vulnerabilities` が null（保存済みファイルが読めず、前回の findings にも items が無い等）のときに失敗すると、「%s に更新した脆弱性データで照合します」と出るが、実際には何も照合していない。この PR で足した文言が事実と違う
**修正方針:** `FeedStatus` から `checking={ !! view.vulnerabilities }` を渡し、照合しているときだけ更新日時の文を出す。それ以外は「取得に成功するまで、既知の脆弱性は照合されません」。e2e にこの組み合わせを追加
**対応:** 73868df。e2e 13 本 green。条件の `checking &&` を外した build では追加したテスト 1 本だけが落ちることを確認（ミューテーション）
