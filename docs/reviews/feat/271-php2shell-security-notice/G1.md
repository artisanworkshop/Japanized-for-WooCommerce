## 指摘
### [G1-1][Copilot][保留:誤検知][woocommerce-for-japan.php:34]
`Requires Plugins: woocommerce` があるので、WooCommerce が無効だと WordPress はこのプラグインを読み込まず、「WooCommerce が無くても出す」は成り立たない、という指摘。
判定: 保留(誤検知)。WordPress 本体の `wp_get_active_and_valid_plugins()`(wp-includes/load.php)は、ファイル名の妥当性・存在・ネットワーク有効化・リカバリーモードしか見ず、依存関係が満たされないプラグインも読み込む。`WP_Plugin_Dependencies::has_unmet_dependencies()` を使うのは有効化時の `validate_plugin_requirements()` と管理画面の通知だけ(WordPress 7.1.3 で確認)。管理画面からは依存されている WooCommerce を無効化できないため頻度は低いが、WP-CLI やフォルダ削除で WooCommerce が無効になった場合でも、このファイルは読まれてモーダルが出る。
**対応:** 根拠を返信し、未解決のまま残す / スレッド: https://github.com/artisanworkshop/Japanized-for-WooCommerce/pull/272#discussion_r4345038705
