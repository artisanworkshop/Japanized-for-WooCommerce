## 指摘
### [R1-1][Medium][tests/Unit/test-paidy-api-response-handling.php:`failed_response_provider()`]
`paidy_is_closed_response()` の 2xx 判定を消しても全テストが通る(mutate-check で NOT CAUGHT を確認)。502 は本文が JSON でなく、400 は `status` が `closed` でないため、2xx 判定が無くても失敗扱いになり、2xx 判定そのものを固定するケースが無い。
**修正方針:** 「409 なのに本文が `{"status":"closed"}`」のケースを provider に足し、取消・キャプチャ・返金・`wc_create_refund()` の 4 テストすべてで失敗を確認する

### [R1-2][Medium][tests/Unit/test-paidy-payment-id-format.php]
キャプチャで ID が不正なときに追加した `send_notice_email()`(店舗への通知メール)をどのテストも確認していない。
**修正方針:** 不正な ID でキャプチャしたとき、通知先へメールが送られ、本文に注文メモと同じ理由が入ることを `tests_retrieve_phpmailer_instance()` で確かめるテストを足す
