## 指摘
### [R1-1][Medium][includes/gateways/paidy/class-wc-gateway-paidy.php:184(コンストラクタの `woocommerce_thankyou_paidy`)]
これまでは Endpoint のインスタンスが全リクエストで `woocommerce_thankyou_paidy` を登録していた。修正後は WooCommerce が一覧を読み込むリクエスト(`wc_template_redirect()` は `is_checkout()` の時だけ)でしか登録されず、checkout 以外のページで thank-you テンプレートを出すファネル系プラグインでは `thankyou_completed()`(オーソリ確定)が動かなくなる。
**修正方針:** 注文ステータスと同じく static の `handle_thankyou()` を `register_checkout_return_hooks()` で 1 回だけ登録し、その中で `get_registered_instance()` を取る。一覧を読み込まないリクエストで完了することをテストで固定する。
