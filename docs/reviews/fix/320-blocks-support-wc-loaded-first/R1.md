- フックのタイミング: `woocommerce_blocks_loaded` は `Packages::on_init`(plugins_loaded 10)→ `Bootstrap::__construct()` からリクエストの種類に関係なく発火する。直接呼んだときに足すフックは、決済レジストリの初期化(init 5、`Payments/Api.php:47`)、`woocommerce_init`(init 0)、Checkout ブロック型の生成(init の `register_blocks`)で、どれも plugins_loaded より後
