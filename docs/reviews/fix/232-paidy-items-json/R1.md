### [R1-L1][Low][includes/gateways/paidy/class-wc-gateway-paidy.php:478]
割引額 0 の判定 `if ( $coupon->get_discount() )` は文字列の真偽値に頼っている。`WC_Order_Item_Coupon::set_discount()` は `wc_format_decimal()` を通すが、末尾のゼロを削るのは float を渡したときだけで、文字列 `"0.00"` はそのまま保存される。`(bool) "0.00"` は真なので、その注文では 0 円のクーポン明細が残る（JSON としては正しく、構文エラーは再発しない。修正前と同じ判定なので回帰ではない）。
**修正方針:** `0.0 !== (float) $coupon->get_discount()` で数値として比べ、`"0.00"` で保存したクーポンのテストを足す
