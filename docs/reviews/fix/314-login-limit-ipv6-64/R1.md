## 指摘
### [R1-1][Medium][tests/Unit/test-jp4wc-login-limiter.php:489-492]
`$bits = 200` の「200 is taken as 128」は、上限 128 の clamp を外しても落ちない。200 は 8 の倍数なので `substr( $packed, 0, 25 )` が 16 バイト全部を返し、端数バイトも無いため、アドレスごとのキー `…::1/200` になってしまう。上限が効くのは 8 の倍数でない 129 以上だけ(clamp なしの 129 は `Uninitialized string offset 16` の警告と `inet_ntop()` の false で、全 IPv6 クライアントが `/129` の 1 キーになる。`php -r` で再現)。
**修正方針:** 200 を 129 にし、その理由をコメントに書く。上限を外す変異で落ちることを mutate-check で確かめる。
