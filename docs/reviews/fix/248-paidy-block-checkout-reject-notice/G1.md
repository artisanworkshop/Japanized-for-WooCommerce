## 指摘
### [G1-1][Codex][Low → 保留(誤検知)][includes/gateways/paidy/class-wc-gateway-paidy.php:308]
`?status[]=rejected` や `?order_id[]=42` のように配列で渡されると、`sanitize_key()` → `strtolower()`、`absint()` → `abs()` に配列が渡り TypeError で fatal になる(P2)、という指摘。/ 判定: 保留(誤検知)
**対応:** WordPress 6.7 以降の `sanitize_key()` は `is_scalar()` の中でだけ `strtolower()` を呼び、配列には `''` を返す。`absint()` は `abs( (int) $x )` で、配列は 0/1 になるだけ(PHP 8.3 で確認)。status が配列なら何もせず、order_id が配列ならログの ID が 1 になるだけ。返信して未解決のまま残す / スレッド: https://github.com/artisanworkshop/Japanized-for-WooCommerce/pull/251#discussion_r4288461318
