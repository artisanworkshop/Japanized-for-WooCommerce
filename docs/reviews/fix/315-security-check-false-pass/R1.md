### [R1-1][Medium][tests/Unit/test-jp4wc-security-checks.php]
正規表現を書き直したのに、元から対応していた `.tgz` / `.tar` / `.rar` / `wp-config.php.orig` / `.save` / `.swp` が data provider に無く、`[-_.]db` の `.` 区切りも固定されていない(文字クラスから `.` を落としても落ちるテストが無い)。A-05 でも、設定オンで 1 本目が一覧を返したときに 2 本目を送らないことと、`/index.php/%postname%/` 形式のパーマリンクがテストされていない(サブエージェント A-2)。
**修正方針:** provider に 9 件(`site.tgz`・`site.tar`・`site.rar`・`wp-config.php.orig`・`wp-config.php.save`・`.wp-config.php.swp`・`shop.db.gz` ほか)を足し、`test_a05_own_setting` に 2 本目が送られないことの検査、`test_a05_rest_route_form_with_pretty_permalinks` に `/index.php/wp-json/` の場合を足す。
