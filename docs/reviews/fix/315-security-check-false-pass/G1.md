### [G1-1][Copilot][High → 誤検知][includes/class-jp4wc-security-checks.php:759]
`add_query_arg()` が値の `/` を URL エンコードするので、2 本目の URL が `?rest_route=%2Fwp%2Fv2%2Fusers` になり、テストのモック(`?rest_route=/wp/v2/users` の URL で引く)と一致しない、という指摘。/ 判定: 保留(誤検知)
**対応:** 修正しない。`add_query_arg()` が `urlencode_deep()` をかけるのは URL に元からあるクエリだけで、足す値は `build_query()` → `_http_build_query( …, false )` でエンコードしない(wp-includes/functions.php)。`get_rest_url()` も基本パーマリンクで同じ `add_query_arg( 'rest_route', $path, $url )` を使う(rest-api.php)。新テストは `?rest_route=/wp/v2/users` の URL で通っており、2 本目の URL を作らない変異では落ちる(= モックの応答が実際に使われている)。/ スレッド: https://github.com/artisanworkshop/Japanized-for-WooCommerce/pull/323#discussion_r4438079505
