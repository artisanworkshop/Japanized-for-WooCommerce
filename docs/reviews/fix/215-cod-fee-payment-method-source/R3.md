## 設計判断の検証（独立サブエージェント）
- **リクエストの `payment_method` を利用可能なゲートウェイと照合しない**: 新しい穴は無い。POST / PUT では WooCommerce が REST 引数の enum（登録済みゲートウェイ ID）で先に弾き、偽 ID・配列・大文字違いはルートに届かない（11.2 と 10.5.3 で実行）。届きうる「登録済みだが利用不可」の ID は WooCommerce が `woocommerce_rest_checkout_payment_method_disabled` で拒否し、注文は確定しない
- **cod / cod2 以外の不一致を許容**: 抜け道は無い。手数料を付けるのは `cod` と `cod2` の分岐だけ。注文か基準のどちらかが cod / cod2 なら不一致は必ず 409（cod と cod2 の食い違いも 409）
- **開始時に退避、終了時に復元**: 先行フィルターの WP_Error、引数検証エラー、permission 失敗、`rest_dispatch_request` の短絡、ルート内の RouteException / Exception では釣り合う。釣り合わないのはルートの途中で `\Error` が抜けた場合だけ（R3-L1）
